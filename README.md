# Есенина — 3D-модель квартиры

Интерактивная 3D-модель квартиры «как сейчас» (сталинка), построенная по плану «конечная».

Открыть: https://t8rhm9k9s5-droid.github.io/esenina/

- `index.html` — вся модель (Three.js r128), размеры в мм от внутренних граней стен.
- `three.min.js`, `OrbitControls.js` — библиотеки рядом с сайтом, без внешних CDN.
- Иконка для экрана «Домой» на iPhone: `apple-touch-icon.png`, полноэкранный режим (`black-translucent`).
